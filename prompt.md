Create a polished, responsive whiskey review blog website with a landing page and **nine individual whiskey review posts**.

The landing page should feature a welcoming hero section, a brief introduction to the blog, and a clearly organized grid of nine review cards. Each card should link to its own full review post and show the whiskey’s name, a short description, and a relevant image.

Each review post should include:
- The whiskey’s name and a concise introduction
- **Color:** describe its appearance in the glass
- **Smell:** describe its aromas
- **Taste:** describe its flavors and finish
- A relevant bottle or tasting image, when available

Use a warm, refined visual style inspired by whiskey tasting rooms: amber and cream tones, dark accents, and readable typography. Make the site easy to navigate and accessible on desktop and mobile. Ensure every image is actually visible: use working image URLs or bundled image files, set appropriate image dimensions and `object-fit`, and include descriptive alt text. If an image cannot load, show a graceful placeholder rather than a broken-image icon.
